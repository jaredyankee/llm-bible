# Contributing to llm-bible

First off, thank you. Genuinely.

## How to contribute

1. Fork the repo
2. Make your changes
3. Open a PR with a short description of what you're adding and why

That's it.

## What we're looking for

- Theses (prompting rules) for the Man or the Machine
- Snippets and patterns worth copy-pasting
- Corrections where I'm wrong (encouraged)
- Model-specific tips and gotchas

## What we're not looking for

- Vague advice that sounds smart but says nothing
- Anything that requires a PhD to understand
- AI-generated slop with no real-world testing behind it

## PR approval

I'll review PRs personally. I might put good ones up for a community vote. 
Truly bad recommendations may end up on the wall of shame. You've been warned.

## Filing an issue

If you have an idea but don't want to write it up yourself, open an issue. 
Use a clear title and explain the reasoning behind your suggestion.

## Code of conduct

Don't be weird.
